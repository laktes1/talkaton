# Толкатрон — Календарь для Контур.Толк

**Репозиторий:** github.com/laktes1/talkaton · **Ветка с доработками:** `feat/etap-7-calendar-extras` ([PR #2](https://github.com/laktes1/talkaton/pull/2))

## Идея

Календарь как полноценный раздел внутри экосистемы Контур.Толк — пятая вкладка рядом с
Чатами, Артефактами, Досками и Контактами. Три вещи, ради которых всё затевается: не
пропускать следующую встречу, не тратить время на постановку новых встреч руками и не
жить в двух календарях одновременно (свой + внешний).

**Вне скоупа:** реальная запись/транскрибация встреч — берём как готовые данные от Толка,
не воспроизводим сами.

## Технические принципы

- **Стек:** Angular + TypeScript (фронт), C# / ASP.NET Core (бэк) — совпадает с реальным
  стеком Толка, на финале компоненты переносятся почти как есть. SQLite на время демо,
  Postgres — при переезде на постоянный стенд. Один `docker compose up` поднимает всё.
- **Время — только в UTC**, таймзона пользователя — отдельное поле. Переделывать это
  позже дороже всего.
- **Повторяемость — по RRULE (RFC 5545)**, не самописным форматом: иначе синхронизация
  с Google/ICS превращается в боль.
- **Anti-Corruption Layer (`ITalkGateway`)** — единственная точка, через которую идёт
  весь обмен с Толком (пользователи, комнаты, саммари, артефакты). Сейчас за ней мок,
  на финале меняется только реализация.
- **Цвета — только через CSS-токены** `var(--tk-*)`, ни одного HEX в компонентах.
- **Вход по имени**, без пароля — временная схема на время демо, на финале заменяется
  на SSO Толка.

## Основная функциональность

Работающий демо-скелет календаря — то, чем уже можно пользоваться сегодня.

### Сетка и навигация — ✅ сделано
День / Неделя / Месяц / Год, переключение, кнопка «Сегодня», навигация вперёд-назад,
поиск по событиям в тулбаре. Мини-календарь месяца сбоку — выбранный день подсвечен
отдельно от сегодняшнего.

### Drag-and-drop и ресайз — ✅ сделано
Перетаскивание встреч между днями и часами, ресайз длительности за нижний край,
плавающий бейдж с текущим временем во время переноса. Пересекающиеся встречи
автоматически раскладываются в отдельные колонки.
⚠️ Шаг привязки к сетке по факту 5 минут (минимальная длительность встречи — 15 минут) —
не совпадает с более ранним ожиданием «шаг 15 минут», просто фиксирую расхождение.

### Создание и редактирование встречи — ✅ сделано
По кнопке, по клику на пустое место в сетке (двойной клик подставляет время) или по
горячей клавише. Форма: тема, дата/время, цвет, видеовстреча в Толк, тумблер «Запись +
ИИ-протокол», повтор (включая «каждую неделю»), описание, участники — поиском или
чипсами готовых списков.

### Артефакты встречи — ✅ сделано, с ограничением
Правая панель встречи: запись, ИИ-протокол, доска, задачи — карточки со стрелкой,
участники со статусами, кнопка «Присоединиться».
⚠️ Панель встроена в CSS Grid и сужает центральную колонку календаря — это не оверлей
поверх сетки и не поповер. Апгрейд до оверлея/поповера — см. «Дополнительные плюшки».

### Списки участников — ✅ сделано
Добавление людей на встречу пачкой. Свои списки: название, цвет из палитры, поиск по
справочнику, выбор чекбоксами. Редактирование и удаление с каскадным сносом связей.

### Дни рождения — ✅ сделано, с известным пробелом
Отдельный календарь, настройка скоупа (шестерёнка): все сотрудники / моё подразделение /
только избранные. Показываются в полосе «весь день», не в основной сетке.
⚠️ Несколько дней рождения в один день — отдельные плашки, без объединения в одну.
Объединение + переход в Стафф — см. «Дополнительные плюшки».

### Мультикалендари — ✅ сделано
Чекбоксы категорий (рабочие встречи, личное, дни рождения, задачи и дедлайны) —
включение/выключение слоёв в сетке.

### Полоса «весь день» и линия текущего времени — ✅ сделано
Отпуска и статусы — отдельно от почасовой сетки. Линия текущего времени с меткой на
сегодняшнем дне.

### Уведомление перед встречей — ✅ сделано
Тост поверх интерфейса + системное уведомление (Web Notifications), настраиваемое время
(0/5/10/15/30 минут), кнопка «Присоединиться», отдельно обработан случай «встреча уже
идёт, вы ещё не в ней». Доставка в другие каналы (Telegram, Mattermost, email, push) —
см. «Дополнительные плюшки».

## Дополнительные плюшки

Поверх основной функциональности. Не блокируют демо, добавляются по остатку времени.

### Грид занятости участников — ✅ сделано
При выборе времени встречи видно, кто из участников занят/свободен — визуальный
таймлайн (`/api/availability`). Отклонившие приглашение не считаются занятыми,
пересекающиеся интервалы сливаются в один.

### Бронирование переговорок — ✅ сделано
Выбор переговорки из списка при создании очной/гибридной встречи. Бэкенд не даёт
забронировать одну комнату на пересекающееся время — реальная проверка конфликтов.

### Ротация по очереди — ✅ сделано
Для списка участников — распределение входящих встреч по кругу, а не всегда одному и
тому же человеку.

### Резервное время до/после встречи (буфер) — ✅ сделано
Настраиваемый буфер растягивает интервал занятости в гриде — соседнюю встречу нельзя
поставить впритык.

### Делегирование — ✅ сделано
Один пользователь разрешает другому создавать и редактировать встречи в своём
календаре от своего имени (секретарь и руководитель). Фактический автор фиксируется
отдельно от организатора — данные не теряются.

### Публичная страница самозаписи — 🟡 частично
Личная ссылка вида «забронировать время у меня» — приглашённый видит занятость и сам
выбирает слот. Ограничение: работает только для уже вошедших в Толкатрон
пользователей — настоящих анонимных внешних гостей система не поддерживает.

### Многоканальные уведомления — ⬜ не сделано
Пользователь сам выбирает, куда дублировать напоминание: push на смартфон (если
установлено приложение Толка), Telegram, Mattermost, email — в дополнение к тосту в
самом Толке.

### Focus Time / блоки фокуса — ⬜ не сделано
Пользователь помечает блок времени как защищённый — система автоматически отклоняет
или помечает конфликтом пересекающиеся приглашения.

### Speedy meetings по умолчанию — ⬜ не сделано
Настройка дефолтной длительности новой встречи — 25/50 минут вместо 30/60, чтобы между
встречами оставался разрыв. Влияет только на новые встречи, старые не трогает.

## Ассистенты

### Постановка встречи из протокола — ⬜ не сделано, детально спроектировано
Модель, которая уже собирает ИИ-саммари, извлекает из протокола прошедшей встречи
договорённость вида «созвонимся в четверг по биллингу» и предлагает готовый черновик:
тема, участники, слот.

Что входит:
- Интерфейс `IMeetingExtractor` (вход — текст саммари + контекст участников, выход —
  черновики встреч); на старте — реализация на фикстурах (`FixtureMeetingExtractor`,
  5-7 сценариев, включая пограничные вроде «договорились созвониться, но без даты»),
  без сети, демо не падает.
- На сетке черновик — серым, с полупрозрачным слоем карточки и отдельной иконкой,
  явно отличимой от обычной встречи.
- В описании черновика — из какого именно мероприятия и протокола он собран:
  расшифровка протокола может быть неверной, человеку нужно быстро понять, откуда
  взялось предложение, а не только слепо принять/отклонить.
- Ничего не создаётся без подтверждения человека — кнопки «Создать» / «Изменить» /
  «Отклонить».
- Ручной вкл/выкл на самой встрече: кнопка «включить постановку через LLM» — не дёргать
  модель на каждую встречу подряд, только когда явно проговорено, что будет новая.
- Самое сложное — автоматический подбор свободного слота по точному составу
  участников новой встречи: кто-то с прошлой встречи может быть не нужен на новой, даже
  если это не проговорено явно. Можно переиспользовать данные грида занятости
  (`/api/availability`, уже готов), но нужен ещё алгоритм автовыбора конкретного слота,
  а не только визуализация для человека.
- Триггер — вебхук «саммари готово» из мок-сервиса Толка (см. «Деплой»).

## Деплой и инфраструктура

### Репозиторий и CI — ✅ сделано
GitHub-репозиторий, ветвление (`main` стабильный, `feat/*` — фичи, PR в `main`). CI:
бэкенд (restore/build/test + проверка расхождения миграций с моделью), фронтенд
(lint/test/prod-сборка), docker-compose smoke-тест. Деплой-джоба с гейтом на зелёный CI.

### VPS, домен, мок-сервис Толка — 🟡 частично
Публичный стенд на VPS с доменом и TLS — сделано. Мок-эмулятор внешнего API Толка
(список сотрудников, комнаты видеовстреч, готовые саммари, артефакты) и заглушка
авторизации SSO — не сделаны, в очереди. Без мока не завести триггер для «Постановки
встречи из протокола» (см. «Ассистенты»).

### Проверка на стенде — ⬜ не сделано
Прогон демо-сценария целиком с несколькими пользователями одновременно, проверка
таймзон и переходов через полночь, замер производительности сетки на ~200 событиях.

### Чаты-дровер — ⬜ не сделано, имеет смысл только на финале
Вкладка «Чаты» сейчас недоступная заглушка. Выпадение чатов поверх календаря (список
диалогов, переписка, поле ответа без потери контекста) — по сути доработка самого
Толка, не отдельного прототипа. Имеет смысл делать только вместе со склейкой с
настоящим Толком, не раньше.

### Склейка с настоящим Толком — ⬜ не сделано
Отдельная ветка в репозитории Толка. Перенос Angular-модуля календаря в их фронтенд с
заменой токенов темы на их дизайн-систему. Замена `ITalkGateway`-заглушки на реальные
внутренние API — единственная точка, где меняется бэкенд-код. Реальная авторизация
вместо входа по имени. Календарь как настоящая вкладка навигации. Реальные записи и
ИИ-протоколы вместо фикстур. Приведение к их конвенциям (линтеры, тесты, code review).
Демо и защита.
